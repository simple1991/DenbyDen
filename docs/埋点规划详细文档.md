## 数据库表结构设计

### 1. 事件表 (events)
存储所有埋点事件的核心表

| 字段名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| id | uuid | 主键，自动生成 | - |
| event_type | text | 事件类型 | `product_exposure`, `product_click`, `add_to_cart`, `email_submit`, `page_dwell`, `page_bounce`, `page_view`, `product_detail_view`, `image_swipe`, `section_expand`, `gift_wrapping_toggle`, `scroll_depth`, `filter_select`, `navigation_click`, `button_click`, `review_carousel_nav`, `currency_selector_open`, `currency_change`, `contact_form_submit`, `faq_expand`, `modal_close`, `search_icon_click`, `mobile_menu_click`, `collection_click`, `collection_scroll`, `cart_modal_open`, `cart_modal_close`, `cart_item_update`, `cart_item_remove`, `cart_modal_link_click` |
| event_category | text | 事件分类 | `exposure`, `click`, `conversion`, `interaction`, `lead` |
| page_type | text | 页面类型 | `home`, `product_detail`, `shop`, `category`, `about`, `contact`, `faq`, `christmas` |
| page_url | text | 页面URL | `/`, `/product/strawberry-bunny-glass-container` |
| user_id | text | 用户标识（localStorage生成的唯一ID） | `user_abc123` |
| session_id | text | 会话ID | `session_xyz789` |
| timestamp | timestamptz | 事件发生时间 | `2024-01-15 10:30:00+00` |
| created_at | timestamptz | 记录创建时间 | `2024-01-15 10:30:00+00` |

## 首页埋点详情

### 页面URL
`http://localhost:3000/`

### 1. 产品卡片曝光（列表页/首页）

**触发时机：**
- 产品卡片进入视口时（使用 Intersection Observer）
- 页面加载时，首屏产品自动曝光

**上传数据：**
```json
{
  "event_type": "product_exposure",
  "event_category": "exposure",
  "page_type": "home",
  "page_url": "/",
  "product_id": "prod_001",
  "product_slug": "strawberry-bunny-glass-container",
  "position": 1,
  "exposure_count": 1,
  "list_type": "new_arrivals",
  "viewport_position": "above_fold"
}
```

**数据表：**
- `events` - 主事件记录
- `product_exposures` - 曝光详情

**实现要点：**
- 使用 Intersection Observer API 检测产品卡片是否进入视口
- 防抖处理，避免重复上报（同一产品同一位置5秒内只上报一次）
- 区分首屏（above_fold）和非首屏（below_fold）

### 5. 页面停留时长

**触发时机：**
- 页面加载时开始计时
- 页面卸载时或用户离开时上报

**上传数据：**
```json
{
  "event_type": "page_dwell",
  "event_category": "interaction",
  "page_type": "home",
  "page_url": "/",
  "dwell_time_seconds": 120,
  "is_bounce": false
}
```

**数据表：**
- `events` - 主事件记录
- `page_dwell_time` - 停留时长详情

**实现要点：**
- 使用 `beforeunload` 和 `visibilitychange` 事件
- 停留时长小于3秒视为跳出（bounce）

## 通用埋点说明

### 用户标识（user_id）
- 首次访问时，在 localStorage 生成唯一ID：`user_${timestamp}_${random}`
- 后续访问复用该ID

### 会话标识（session_id）
- 每次页面加载时生成：`session_${timestamp}_${random}`
- 同一标签页内会话ID保持一致
- 新标签页或刷新页面时生成新的会话ID

### 时间戳
- 所有时间使用 UTC 时间
- 格式：ISO 8601

### 数据上报策略
1. **实时上报**：关键转化事件（加入购物车、邮箱提交、联系表单提交、购物车内商品修改/删除、购物车弹窗链接点击）
2. **批量上报**：曝光类事件、交互类事件（FAQ展开/收起、模态框关闭、Collections滚动），每5秒或累积10条后批量上报
3. **延迟上报**：页面停留时长、页面曝光，页面卸载时上报

### 全局组件埋点说明
以下组件在所有页面都可能出现，埋点规则统一：
- **购物车弹窗**：可在任何页面打开，埋点规则见首页埋点详情第14节，`page_type`和`page_url`应记录实际打开弹窗时的页面信息
- **导航栏**：所有页面的导航栏点击埋点规则相同，见首页埋点详情第7节
- **货币选择器**：所有页面的货币选择器埋点规则相同，见首页埋点详情第10节

### 错误处理
- 网络错误时，数据暂存到 localStorage
- 页面重新加载时，尝试重新上报
- 最多重试3次，超过3次则丢弃

### 隐私保护
- 邮箱地址仅存储，不完整上报（可上报hash值）
- 不收集用户IP地址
- 不收集设备指纹信息
