# Supabase 数据库设置说明

## 问题说明

如果遇到以下错误：

```
Failed to insert events: 
{code: 'PGRST205', message: "Could not find the table 'public.events' in the schema cache"}
```

这表示 **Supabase 数据库中还没有创建埋点分析所需的表**。

## 解决方案

### 步骤 1：打开 Supabase Dashboard

1. 访问 [Supabase Dashboard](https://app.supabase.com/)
2. 登录并选择您的项目

### 步骤 2：打开 SQL Editor

1. 在左侧菜单中选择 **SQL Editor**
2. 点击 **New Query** 创建新的查询

### 步骤 3：执行 SQL 脚本

1. 打开项目中的 `docs/supabase_schema.sql` 文件
2. 将整个文件的内容复制到 SQL Editor
3. 点击 **Run** 或按 `Ctrl+Enter` (Windows) / `Cmd+Enter` (Mac) 执行脚本

### 步骤 4：验证表是否创建成功

1. 在左侧菜单中选择 **Table Editor**
2. 您应该能看到以下表：
   - `events` - 主事件表
   - `product_exposures` - 产品曝光表
   - `product_clicks` - 产品点击表
   - `cart_actions` - 购物车操作表
   - `email_captures` - 邮箱留资表
   - `page_interactions` - 页面交互表
   - `page_dwell_time` - 页面停留表

### 步骤 5：刷新应用

执行 SQL 脚本后：
1. 刷新您的应用页面
2. 错误应该消失，埋点分析功能将正常工作

## 错误处理说明

代码已经添加了智能错误处理：

- ✅ 当检测到表不存在时，分析功能会自动禁用
- ✅ 避免无限重试和控制台错误刷屏
- ✅ 在开发环境会显示友好的警告信息
- ✅ 生产环境不会显示错误，避免影响用户体验

## 注意事项

1. **Row Level Security (RLS)**：脚本已配置 RLS 策略，允许匿名用户插入数据
2. **索引**：脚本已创建必要的索引以提高查询性能
3. **外键约束**：详细表（如 `product_exposures`）通过外键关联到主表 `events`

## 常见错误及解决方案

### 错误 1：表不存在 (PGRST205)

```
Failed to insert events: 
{code: 'PGRST205', message: "Could not find the table 'public.events' in the schema cache"}
```

**原因**：数据库表还没有创建。

**解决方案**：执行 `docs/supabase_schema.sql` 脚本创建所有表。

---

### 错误 2：RLS 策略违反 (42501)

```
Failed to insert events: 
{code: '42501', message: 'new row violates row-level security policy for table "events"'}
```

**原因**：行级安全（RLS）策略配置有问题，通常是策略名称冲突导致。

**解决方案**：

1. 打开 Supabase Dashboard 的 SQL Editor
2. 执行 `docs/fix_rls_policies.sql` 脚本
   - 这个脚本会删除旧的冲突策略
   - 然后创建新的唯一名称策略
3. 刷新应用页面

**注意**：如果您之前已经运行过 `supabase_schema.sql`，这个错误是因为旧版本的脚本使用了重复的策略名称。新版本的脚本已经修复了这个问题。

---

## 故障排除

如果执行 SQL 脚本后仍然遇到问题：

1. **检查连接**：确保 Supabase 项目 URL 和 API Key 配置正确
2. **检查权限**：确保 API Key 有正确的权限（应该使用 `anon` key，不是 `service_role` key）
3. **查看日志**：在 Supabase Dashboard 的 Logs 中查看是否有其他错误
4. **重新运行脚本**：如果表已部分创建，可以先删除相关表后重新运行脚本
5. **检查 RLS 策略**：在 Supabase Dashboard 的 Authentication → Policies 中查看策略是否正确创建
