## ⚠️ 常见问题

### Q1: 策略创建了但还是 401？

**检查项**：
1. ✅ API key 是否正确（从 Supabase Dashboard Settings → API 获取）
2. ✅ 环境变量是否设置正确
3. ✅ 是否重启了开发服务器
4. ✅ 策略中的角色是否包含 'anon'

### Q2: API key 格式是什么？

**正确的格式**：
- JWT token 格式
- 通常以 `eyJ` 开头
- 长度较长（200+ 字符）
- 示例：`eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...`

**错误的格式**：
- `sb_publishable_xxx` ❌
- 很短的字串 ❌

### Q3: 如何确认使用的 key 是否正确？

在浏览器控制台的 Network 标签中：
1. 找到失败的请求（401）
2. 查看 Request Headers
3. 找到 `apikey` 字段
4. 检查是否以 `eyJ` 开头（JWT token 格式）
